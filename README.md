# 回数券の残り回数ノート（1画面デモ）

Claude Codeで作成（七海）。

## できること
- 会員（名前）×回数券（購入日・総回数・残り回数・期限）を一覧にし、「1回消化」で残りが減って日付が残る（「戻す」で直前の消化を取り消せる）。
- 期限が近い（14日以内）・期限切れ・残り少（2回以下）・使い切りを、色と文字の両方で表示。検索と並べ替えができる。
- CSV書き出し／読み込み（Excelで開ける形式）。読めない行は取り込まず、行番号と理由つきで赤く表示する。

## 使い方
1. `index.html` をブラウザで開く（最初は架空のサンプル。「全部消す」で空になる）。
2. 上の欄で名前・購入日・総回数・期限を入れて「追加」。来店のたびに「1回消化」を押す。
3. 手元に控えを残すときは「CSV書き出し」。列は 名前,購入日,総回数,残り回数,期限,消化日（消化日は `;` 区切り）。

## 限界
- データはこのブラウザの中（localStorage）だけに保存。端末やブラウザを変える・サイトデータを消すと見えなくなるので、CSVでの控えを前提にしている。複数人での同時編集・LINEとの連携はしない。
- 期限の警告日数（14日）と「残り少」（2回）は固定。振替や休会の扱い、料金の計算はしない。表示は目安で、最終確認は利用者自身が行う。
- 入力・CSVは画面内で処理するだけで外部へ送信しない。依存なしの単一HTML。

## 検証
- `node verify.mjs`：読み取り・消化/取り消し・期限判定の境界・CSV往復の固定ケース＋乱数100回。
- `node ui-check.cjs <playwrightのnode_modules>`（`CHROME_PATH`で実行ファイル指定可）：headless chromiumで画面操作・CSV・390/360px幅・外部通信0・JSエラー0を確認。
